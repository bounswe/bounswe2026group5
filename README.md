# Campus-Neighborhood Mentorship Network

![Status](https://img.shields.io/badge/status-active-success.svg)

## 📌 About The Project

Campus Neighborhood Mentorship Network is a platform designed to connect students for academic and professional guidance. This repository contains the source code for both the frontend client and the backend API services.

## 🚀 Tech Stack

**Frontend:**
* React
* TypeScript
* TailwindCSS
* (Additional libraries like TanStack, Shadcn, etc.)

**Backend:**
* Django
* Python
